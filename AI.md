For this project, I used Google Gemini to help me further understand some of the core concepts of Laravel that the
documentation and other guides alone were unhelpful in solving, such as how the frontend connecting to the backend
differs from other frameworks I've previously used, like Spring Boot.

The responses given were extremely helpful, especially because I was able to take things step-by-step
and ask further questions when I needed a bit more help with some topics.

When I got the further explanations, I cross-referenced this with the Laravel documentation and tutorials
hosted on the official Laravel website to see if I was on the right track.
